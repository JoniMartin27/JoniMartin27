## 🇪🇸 Sobre mí

Construyo **sistemas de agentes de IA** y las herramientas que los rodean: orquestación de flotas de agentes, observabilidad, automatización y benchmarking de modelos. Trabajo de punta a punta — desde la infraestructura backend en TypeScript y Python hasta interfaces y apps móviles.

Mi proyecto principal es **AGENT-OS**, una capa de control para dirigir flotas de agentes de IA con la disciplina de un equipo de ingeniería real. Alrededor de él construyo herramientas como **Lookspan** (observabilidad local-first para agentes) e **InferBench** (benchmarking de motores de inferencia LLM).

También diseño y publico **juegos móviles** (Phaser + Capacitor) como parte de una pequeña "fábrica de juegos" propia, y construyo bots y automatizaciones que uso a diario.

> 🇬🇧 **In short:** I build AI agent systems and the tooling around them — fleet orchestration (AGENT-OS), agent observability (Lookspan), and LLM inference benchmarking (InferBench) — plus mobile games (Phaser + Capacitor) and everyday automation bots. Full-stack across TypeScript and Python, with a strong local-first, privacy-first bent.
